# 🌌 Cyber Todo

> Личный неоновый таскер для управления задачами, покупками и событиями. PWA-приложение с автоматическими Push-уведомлениями.

**Демо:** [https://vetrovtimur.github.io/Cyber-todo/](https://vetrovtimur.github.io/Cyber-todo/)

## 🚀 Основные возможности

- **🔐 Авторизация:** Вход по Email и паролю (Firebase Auth) с опцией «Запомнить меня».
- **📝 Задачи:** 
  - Дедлайны с умной подсветкой (просрочено/сегодня).
  - Категории (Работа / Дом / Личное).
  - Фильтрация по статусу и категориям.
  - Умная сортировка (сначала невыполненные с дедлайном).
- **🛒 Покупки:** Список с указанием количества, статусом «Купил» и подтверждением удаления.
- **📅 Календарь событий:** Отметки праздников, дней рождения и дней памяти. Цветные индикаторы и RGB-подсветка активного дня.
- **📱 PWA:** Устанавливается на телефон (iOS/Android) как нативное приложение, работает офлайн.
- **🔔 Push-уведомления:** Автоматические напоминания через Firebase Cloud Messaging и GitHub Actions.
  - Утренний дайджест (в 09:00).
  - Напоминание о дедлайнах (в 15:00).
  - Напоминание о событиях (в 06:00 и 23:00).

## 🛠️ Технологии

**Фронтенд:**
* HTML5, SCSS (с использованием CSS Grid / Flexbox)
* Vanilla JavaScript (ES-модули, без тяжелых фреймворков)

**Сборка:**
* Gulp 5
* esbuild (для быстрой сборки JS)
* sharp (для авто-генерации WebP/AVIF изображений)

**Бэкенд и База данных:**
* Firebase (Firestore, Authentication, Cloud Messaging)
* Node.js (скрипт для отправки уведомлений)

**Деплой и CI/CD:**
* GitHub Pages (хостинг статики)
* GitHub Actions (запуск бэкенда по расписанию)

## ⚙️ Установка и запуск

1. **Клонируй репозиторий:**
   ```bash
   git clone https://github.com/VetrovTimur/Cyber-todo.git
   cd Cyber-todo
   ```

2. **Установи зависимости:**
   ```bash
   npm install
   ```

3. **Запусти режим разработки:**
   ```bash
   npm run dev
   ```
   *Сайт откроется на `http://localhost:3000`.*

## 📜 Доступные команды

* `npm run dev` — Запуск локального сервера (BrowserSync) с отслеживанием изменений.
* `npm run build` — Продакшн-сборка (минификация, хэширование, Critical CSS).
* `npm run deploy` — Сборка и отправка готового сайта в ветку `gh-pages` на GitHub Pages.
* `npm run lint` — Проверка JS и SCSS линтерами (ESLint, Stylelint).
