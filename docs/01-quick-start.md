# Быстрый старт

## Установка
1. Установи зависимости: `npm install`
2. Запусти режим разработки: `npm run dev`

## Основные команды
* `npm run dev` — Запускает локальный сервер (BrowserSync), следит за изменениями и собирает проект в папку `dist/`.
* `npm run build` — Создает продакшн-версию в папке `build/` (минифицирует код, добавляет хэши к файлам, сжимает картинки).
* `npm run clean` — Очищает папку сборки (оставляя кэш картинок и шрифтов).
* `npm run clean:all` — Полностью удаляет папку сборки.
* `npm run analyze` — Создает отчет по размеру JS-бандла (открывается в браузере).

## Структура проекта
* `src/` — Исходники (HTML, SCSS, JS, картинки, шрифты).
  * `src/parts/` — HTML-компоненты (хедер, футер и т.д.).
  * `src/img/` — Исходные картинки (каждая картинка в своей папке).
* `gulp/` — Конфигурация и таски сборки.
* `dist/` — Папка для разработки (создается автоматически).
* `build/` — Папка для продакшена (создается автоматически).

## Полезные фишки
* Если ты добавил новую картинку или шрифт, но сборка их не видит (из-за кэша), запусти сборку с флагом `--force`:
  `npm run dev -- --force`
