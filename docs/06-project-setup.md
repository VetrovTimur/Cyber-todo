# Настройка сборки под новый проект (Чек-лист)

Этот файл — шпаргалка того, что нужно изменить в сборке, когда ты начинаешь делать новый сайт. Движок сборки (папки `tasks` и `custom`) трогать не нужно, все настройки вынесены в `gulp/config.js`.

## 1. Глобальные настройки сайта (SEO и Open Graph)
Открой `gulp/config.js` и найди блок `const site = { ... }`.
Замени там:
*   `url` — на реальный адрес сайта (например, `https://my-new-site.ru`).
*   `name` — на название проекта.
*   `description` — краткое описание сайта.
*   `ogImage` — название картинки для соцсетей (саму картинку положи в корень `src/static/`).

## 2. Настройки микроразметки (Schema.org)
В том же `config.js` найди блок `const schema = { ... }`.
*   Поменяй название организации, ссылку на логотип и описание.
*   Раскомментируй и добавь ссылки на соцсети в массив `sameAs` (если они есть).

## 3. Настройки фавиконок
Найди блок `const faviconsConfig = { ... }`.
*   Поменяй `appName`, `appShortName`, `appDescription` и `theme_color` (цвета под бренд).
*   Сам исходник фавиконки (картинку `favicon.svg` или `favicon.png`) закинь в папку `src/`.

## 4. Настройки шрифтов
Найди блок `const preloadFonts = { ... }`.
*   Поменяй `mainFamily` на название основного шрифта проекта (например, 'Roboto' или 'Montserrat').
*   В `weights` укажи, какие веса этого шрифта нужно предзагружать в браузере (обычно 400 и 700).
*   *Не забудь удалить старые шрифты из папки `src/fonts/` и закинуть туда новые.*

## 5. Настройки картинок
Найди блок `const imageSizes = [ ... ]`.
*   Здесь указано, какие размеры будут генерироваться. Если для нового проекта нужны другие брейкпоинты, поменяй их. Если все устраивает — не трогай.

## 6. Настройки Critical CSS
Найди блок `const criticalCss = { ... }`.
*   `enabled: true` — включить/выключить.
*   `mode: 'manual'` — по умолчанию ручной режим (ты сам оборачиваешь стили комментариями `/*! CRITICAL:... */`). Если хочешь, чтобы сборка сама вычисляла критический CSS, поменяй на `'auto'`.

## 7. Очистка старых страниц и данных
*   Удали старые HTML-файлы из `src/` (например, `about.html`, `contacts.html`) и создай свои.
*   В папке `src/parts/` обнови `header.html` и `footer.html` под новый дизайн.
*   Очисти папку `src/img/` от старых картинок.
*   В `package.json` поменяй поле `"name"` на название нового проекта.
