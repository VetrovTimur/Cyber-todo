# Как верстать HTML

В этой сборке используются специальные маркеры для автоматизации.

## 1. Вставка компонентов (Инклюды)
Для вставки частей страницы (из папки `src/parts/`) используется плагин `gulp-file-include`:

```html
@@include('parts/header.html')
```

Также в `<head>` автоматически вставляются сгенерированные фавиконки:

```html
@@include('favicon.html')
```

## 2. Вставка SVG-иконок `{{icon}}`
Плагин `gulp-icon` вставляет иконки из спрайтов. Он принимает три аргумента:
`{{icon("имя_файла_без_svg", "css_класс", "тип")}}`

*   `имя` — имя SVG-файла в папке иконок.
*   `класс` — CSS-класс для тега `<svg>` (можно оставить пустым `""`).
*   `тип` — `mono` (перекрашивается через CSS `color`) или `multi` (остается цветной).

**Примеры из проекта:**

```html
<!-- Без дополнительного класса -->
{{icon(svg1, "", "mono")}}

<!-- С классом icon--accent -->
{{icon(svg2, "icon--accent", "mono")}}
```

## 3. Вставка картинок `{{picture}}`
Плагин `gulp-picture` автоматически генерирует тег `<picture>` с AVIF, WebP, Retina и адаптивными размерами (`srcset`).

**Синтаксис:**
`{{picture("имя_папки", "css_класс", "alt_текст")}}`

**Пример из проекта:**

```html
{{picture(img1, "", "Демонстрация адаптивного изображения")}}
```

⚠️ **Важно:** Картинка-исходник (например, `img1.jpg`) должна лежать в папке `src/img/img1/`.

## 4. Служебные маркеры в `<head>`
В `<head>` каждой страницы должны быть специальные комментарии. Сборка сама заменит их на нужные теги при сборке:

*   `<!-- preload-fonts -->` — вставит `<link rel="preload">` для критических шрифтов.
*   `<!-- critical-css -->` — сюда в продакшене вставится критический CSS.
*   `<!-- og-tags -->` — вставит Open Graph и Twitter карточки.
*   `<!-- schema -->` — вставит JSON-LD разметку Schema.org (настройки в `config.js`).
