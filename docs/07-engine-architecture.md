# Архитектура движка Gulp

Этот файл — краткая карта того, как устроена сама сборка (папка `gulp/`). Тебе это понадобится, только если захочешь добавить новую задачу или понять, почему что-то работает именно так. В 99% случаев при верстке сюда заглядывать не нужно.

## 1. Главный пульт: `gulp/config.js`
Здесь хранятся **все** пути к папкам (`paths`), настройки размеров картинок (`imageSizes`), настройки SEO (`site`, `schema`), шрифтов и фавиконок. Если нужно поменять путь к папке с картинками или название сайта — ты меняешь это только здесь.

## 2. Папка `gulp/tasks/` — Механика
Здесь лежат файлы, отвечающие за конкретные задачи. Каждый файл делает что-то одно:
*   `clean.js` — очищает папки `dist/` или `build/`.
*   `html.js` — собирает HTML (вставляет инклюды, вызывает кастомные плагины).
*   `styles.js` / `scripts.js` — собирают CSS и JS.
*   `images.js` / `fonts.js` — обрабатывают картинки и шрифты.
*   `serve.js` / `watch.js` — запускают локальный сервер и следят за изменениями файлов.

## 3. Папка `gulp/custom/` — Твои уникальные фишки
Это самописные плагины (Node.js Stream Transforms). Они не скачаны с npm, а написаны под этот проект. **Их трогать вообще не нужно.**
*   `gulp-picture.js` — превращает `{{picture(...)}}` в тег `<picture>`.
*   `gulp-icon.js` — вставляет SVG-иконки из спрайтов.
*   `gulp-image-cache.js` / `gulp-font-cache.js` — кэшируют обработанные файлы, чтобы dev-сборка запускалась за секунды.

## 4. Дирижер: `gulp/index.js`
Этот файл импортирует все задачи из `tasks/` и выстраивает их в правильную последовательность. 
*   Сначала выполняется `clean` (очистка).
*   Потом **параллельно** собираются картинки, шрифты и спрайты.
*   Генерируются `@font-face` (задача `fontFace`).
*   Потом собираются HTML, стили и скрипты.
В конце файла экспортируются готовые команды (`build`, `default` и т.д.).

## Как добавить новую задачу (если очень нужно)
1. Создай файл с задачей в `gulp/tasks/` (например, `myTask.js`).
2. Если нужны пути — добавь их в `config.js`.
3. Импортируй задачу в `gulp/index.js` и добавь её в `gulp.series` или `gulp.parallel`.
4. Добавь её в экспорт внизу `index.js`.
