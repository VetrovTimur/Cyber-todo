## Главные правила
* Не меняй файлы в папках `dist` или `build` — они перезаписываются сборкой.
* Все исходники лежат в папке `src`.
* Если картинка или шрифт не обновились, используй флаг `--force` при запуске (например, `npm run dev -- --force`).
* Движок сборки (папки `gulp/tasks` и `gulp/custom`) трогать не нужно. Все настройки проекта лежат в `gulp/config.js`.
