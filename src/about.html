Что такое Gulp Starter и зачем он нужен

Gulp Starter — это готовая сборка для веб-проектов. В неё входит компиляция SCSS, сборка JS через esbuild, оптимизация изображений, работа со шрифтами и SVG-спрайтами.

Сборка поддерживает два режима: dev для разработки (с сервером и watch) и prod для деплоя (с минификацией, хэшами и critical CSS).

Что внутри

  • SCSS → CSS с автопрефиксами
  • JS через esbuild (bundle + minify)
  • WebP и AVIF с retina-генерацией
  • SVG-спрайты mono и multi
  • Critical CSS per-page
  • SEO: OG, Schema.org, sitemap, robots
